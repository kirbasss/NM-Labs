Задача 3.4. Численное дифференцирование
Табличные данные:
i = 0: x = -1.0000000000, y = -0.5000000000
i = 1: x = 0.0000000000, y = 0.0000000000
i = 2: x = 1.0000000000, y = 0.5000000000
i = 3: x = 2.0000000000, y = 0.8660300000
i = 4: x = 3.0000000000, y = 1.0000000000

x* = 1.0000000000

=== Численное дифференцирование ===
Используются точки:
x0 = 0.0000000000, y0 = 0.0000000000
x1 = 1.0000000000, y1 = 0.5000000000
x2 = 2.0000000000, y2 = 0.8660300000
x* = 1.0000000000

Формула для первой производной:
f'(x) ≈ (y1-y0)/(x1-x0) + [ ((y2-y1)/(x2-x1) - (y1-y0)/(x1-x0)) / (x2-x0) ] * (2x - x0 - x1)

(y1 - y0)/(x1 - x0) = (0.5000000000 - 0.0000000000)/(1.0000000000 - 0.0000000000) = 0.5000000000
(y2 - y1)/(x2 - x1) = (0.8660300000 - 0.5000000000)/(2.0000000000 - 1.0000000000) = 0.3660300000
correction = (0.3660300000 - 0.5000000000)/(2.0000000000 - 0.0000000000) = -0.0669850000
f'(x*) = 0.5000000000 + -0.0669850000 * (2*1.0000000000 - 0.0000000000 - 1.0000000000) = 0.4330150000

Формула для второй производной:
f''(x) ≈ 2 * [ ((y2-y1)/(x2-x1) - (y1-y0)/(x1-x0)) / (x2-x0) ]

f''(x*) = 2 * -0.0669850000 = -0.1339700000
